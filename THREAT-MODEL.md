# DataDeal threat model

DataDeal accepts a public domain from a visitor or extension, fetches publisher documents and runs signed-out browser visits. An offline analyst interprets selected evidence. A worker publishes a versioned snapshot in PostgreSQL. Visitors can read its public findings. The account owner, an eligible reward holder or a Pro subscriber can access additional data according to the endpoint.

This model covers the web app, scanner, worker, extension and provider integrations in the November 25, 2026 workspace. It describes controls in source and dependencies that still require verification in the intended hosting environment.

## Scan and publication

**A submitted domain can direct server traffic.** A visitor chooses the domain. Its publisher controls DNS, redirects, scripts, frames and subresources. The document fetcher resolves the host, rejects non-public addresses, pins the connection to the resolved address, checks redirect scope and caps response size. Chromium runs with its sandbox enabled, fresh contexts, downloads disabled and service workers blocked. Browser requests rely on the configured egress proxy. A worker-ready event establishes that Chromium can launch. It does not establish which destinations the deployed proxy allows. Internal services, instance metadata, the database and management interfaces must be unreachable from the browser network. [Document acquisition](packages/scanner/index.ts#L43) · [Browser launch](apps/worker/run.ts#L36) · [Context creation](apps/worker/consent-observation.ts#L241) · [Local proxy](tools/local-browser-proxy.ts#L12)

**A hostile document reaches a parser on the worker host.** PDF extraction passes bytes to a local executable over standard input, with a filtered environment, input/output bounds and timeout. The converter runs with the worker's OS identity. A child process is not a filesystem or network isolation boundary. A parser compromise could reach resources available to that identity. Keep Poppler and Chromium patched, run the worker unprivileged and restrict its mounts and network access. The web and worker use the same database service; production database-role isolation requires an operator decision. [PDF conversion](packages/scanner/pdf-document.ts#L19) · [Retrieval regressions](packages/scanner/pdf-retrieval.test.ts) · [Worker database connection](apps/worker/run.ts#L33)

**The publisher can supply misleading policy text and identifier-shaped fields.** Its HTML, PDFs and requests are evidence supplied by the subject of the report. Browser observations become bounded classifications. Optional identifier matching occurs within an isolated visit. The model receives selected excerpts and observations. A citation must resolve to supplied evidence, and validated policy claims remain declarations. Deterministic rules decide whether the measured Accept all scenario supports a headline score. A real quotation can still be misleading and an observed connection alone cannot prove resale. Preserve scenario, source and confidence when changing either pipeline. [Request classification](apps/worker/request-fields.ts) · [Identifier matching](apps/worker/identifier-match.ts) · [Candidate validation](packages/ai/index.ts#L335) · [Headline selection](packages/scoring/index.ts#L137) · [Contextual scoring tests](packages/scoring/contextual.test.ts)

**Repeated requests can consume browser and AI capacity or burden the target.** The public endpoint checks origin and domain, applies account or time-bucketed client limits and passes admitted work to the bounded queue. The database enforces the domain cooldown and worker lease. A guest client bucket depends on a trusted IP header and secret. The edge must replace that header and prevent direct origin access. Per-client rate limits do not cap spending across many independent clients. ## Extension and release credentials

The extension can inspect the active site on user action. Automatic lookup and form reminders require an optional host permission. A public lookup reveals the registrable domain to DataDeal; the background fetch omits credentials. The separate privacy-profile request can include a DataDeal session. The content script locates suitable controls to place a reminder. Expanding its privileges to collect browsing-session traffic or form values would create a new boundary that this model does not cover. [Manifest](apps/extension/wxt.config.ts#L41) · [Lookup](apps/extension/entrypoints/background.ts#L89) · [Account preference](apps/extension/entrypoints/popup/main.tsx#L154) · [Form reminder](apps/extension/entrypoints/form-reminder.ts)

The local analysis runner uses a development OAuth session. The production worker takes its project API key from the worker environment. The standalone web builder removes dotenv files and rejects local analysis tooling. Protect the worker's API key, the web app's authentication and billing secrets, and the build-only HeroUI license separately. Compromise of the worker or its database credentials has a wider impact than compromise of a scanned website. Verify release artifact contents, service identities, backup access and retention on the intended host.
